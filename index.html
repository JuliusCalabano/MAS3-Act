Learning Objectives

  1. Configure Microsoft Word page settings.
  2. Apply consistent paragraph and text formatting.
  3. Create APA 7 formatted research tables.

Configure the basic document settings.

Task Objective

Set the correct page size, orientation, margins, and other page settings for the research manuscript.

Required Page Settings

Setting Required Format
Paper Size Letter / A4 — follow instructor requirement

Task Objective

Format the research manuscript so that paragraphs, text alignment, indentation, and spacing are consistent.

Formatting Areas to Check

Element What to Check
Alignment Use the required alignment consistently.
Indentation Apply appropriate first-line indentation.
Line Spacing Use the required spacing.
Paragraph Spacing Remove inconsistent before/after spacing.
Font Use the required academic font.
Home → Paragraph → Line and Paragraph Spacing
Tip: Use the Paragraph dialog box for more precise indentation and spacing settings.

Task Objective

Convert the provided raw data into a properly organized research table and apply APA 7 formatting. This section should be in separate page with LANDSCAPE ORIENTATION

APA 7 Table Example

Table 1
Respondents' Assessment of the Research Variables
Variable M SD
Variable A 4.25 0.52
Variable B 4.11 0.61
Variable C 4.36 0.48
Note. M = mean; SD = standard deviation.
Remember: Do not simply copy the raw data into a table. Organize it logically and apply the required APA 7 structure.

Task Objective

Insert the appropriate header throughout the research manuscript and make sure it appears consistently.

Instructions

  1. Go to the Insert tab.
  2. Select Header.
  3. Choose an appropriate header layout.
  4. Enter the required manuscript information.
  5. Check the header on multiple pages.
  6. Make sure the header does not interfere with the body text.
Insert → Header → Choose Header
Tip: Double-click the top portion of a page to quickly open the Header and Footer area.

Task Objective

Create two different page-numbering systems within the same Microsoft Word document.

Required Numbering Format

Document Section Page Number Format

Important: Do not use a regular page break when you need different numbering formats. Use a Section Break – Next Page.

Task Objective

Apply Heading 1, Heading 2, and Heading 3 styles so that the research manuscript's structure appears correctly in the Navigation Pane.

Instructions

  1. Locate the major sections of the manuscript.
  2. Apply Heading 1 to major headings.
  3. Apply Heading 2 to secondary headings.
  4. Apply Heading 3 to lower-level headings.
  5. Open the Navigation Pane.
  6. Check that headings appear in the correct hierarchy.
Home → Styles → Heading 1 / Heading 2 / Heading 3
View → Navigation Pane

Recommended Heading Structure

Style Example
Heading 1 CHAPTER 1 – THE PROBLEM AND ITS BACKGROUND
Heading 2 Introduction
Heading 2 Background of the Study
Heading 3 Research Context
Tip: If a heading does not appear in the Navigation Pane, check whether an actual Word Heading Style was applied. Making text bold does not create a navigation heading.
